# بوت SAV - Telegram

## الأوامر في القروب

**تسجيل طلب جديد:**
```
اسم: محمد بن علي
هاتف: 0661234567
عنوان: حي السلام بلوك 3
عطب: تسرب مياه
```

**عرض الطلبات المفتوحة:**
```
/list
```

**تسجيل إنجاز:**
```
/done SAV-001 تم تغيير الصمام وإصلاح التسرب
```

## النشر على Railway

1. اذهب إلى railway.app
2. سجّل بـ GitHub
3. New Project → Deploy from GitHub
4. أضف المتغيرات:
   - BOT_TOKEN = توكن البوت
   - GROUP_ID = -5137002293
